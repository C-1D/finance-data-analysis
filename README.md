# 金融数据分析学习项目

这是一个使用 Python 进行金融与宏观经济数据分析的学习项目。

## 项目目标

本仓库将学习内容分为三个层次：

1. 数据获取、清洗与描述统计
2. 金融计量与经济时间序列分析
3. 风险管理、机器学习与金融科技应用

## 第一个项目：Financial Data Science in Python Notebooks

原始项目：
https://github.com/terence-lim/financial-data-science-notebooks

中文学习入口：
[financial-data-science-notebooks/README_CN.md](financial-data-science-notebooks/README_CN.md)

## 技术栈

- Python
- pandas
- NumPy
- matplotlib
- statsmodels
- scikit-learn
- Jupyter Notebook

## 学习顺序

先完成股票收益率和描述统计，再学习时间序列、回归诊断、因子模型和风险度量。每完成一个 Notebook，都要记录数据来源、统计方法、主要结果和局限性。
