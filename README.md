# Finance Data Analysis
Python project for macroeconomic & financial data statistics and visualization.

## Project Introduction
This project uses Python to process financial and macroeconomic data, including data cleaning, descriptive statistics, correlation analysis and data visualization.
Tech stack: pandas, numpy, matplotlib.

项目简介：
本项目使用Python完成金融与宏观经济数据处理，包含数据清洗、描述统计、相关性分析与可视化。
工具库：pandas, numpy, matplotlib
